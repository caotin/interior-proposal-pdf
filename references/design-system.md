# Editorial design system

Use this system for warm interior proposals unless the user supplies another direction. The bundled [demo contact sheet](../assets/demo-overview.jpg) illustrates the treatment. The complete fictional example is available in the public repository. The demo is fictional and is not a source of commercial terms.

## Visual language

- Default page: 16:9, 1280 × 720 CSS px, 960 × 540 PDF pt. Choose a different format when required; do not impose a fixed number of pages.
- Palette: warm paper `#f1ece3`, neutral image background `#e7dece`, dark brown text `#332c24`, oak accent `#a47a50`, olive `#777851`, terracotta `#a86550`. These are design suggestions, not a brand specification.
- Typography: expressive serif headings against restrained sans-serif copy and uppercase tracked labels. Use CSS letter spacing rather than inserting spaces between letters.
- At the default canvas: 48–58 px page margins; headings around 48–68 px; body 16–19 px; labels 10–12 px; folios 9–11 px. Adjust for language and content density without sacrificing readability.
- Let imagery occupy roughly 45–65% of room/product pages. Favor neutral product backdrops and soft contact shadows, fine rules, generous whitespace, and prominent serif prices.
- Alternate left/right image placement, single products, two-product pages, full-bleed photographs, and summary pages to build rhythm.
- Keep a consistent project identifier in the footer and the page number at the opposite edge.

## Page roles

| Role | Composition and purpose |
| --- | --- |
| Cover | Full-bleed room image, restrained contrast overlay, large concept title, project metadata |
| Contents | Narrow room crop with concise section titles and actual page numbers |
| Concept | Short narrative, one meaningful quotation, two or three image crops |
| Moodboard | Keywords with deliberately composed material/detail crops |
| Palette | Named colors and intended applications; 60/30/10 is a design direction, not a quantity survey |
| Materials | Four or five swatches with stable material IDs and intended locations |
| Floor plan | Supplied plan, room legend, and an explicit statement of measurement reliability |
| Lifestyle | Full-bleed image with a few lines showing everyday use |
| Room overview | Scene image, matching item IDs, room inventory, verified subtotal |
| Single product | Large complete silhouette, description, material, sourced dimensions, unit price, amount |
| Two products | Two spacious rows with alternating images and concise specifications |
| Product group | One contextual image with separate IDs, quantities, and prices for every billable item |
| Estimate | Group subtotals, prominent grand total, scope exclusions, supplied commercial conditions |
| Process / closing | Four clear delivery stages and a short closing message |

A short proposal can combine roles. Preserve the narrative from concept to solution, details, scope/cost, and next steps instead of adding pages merely to fill a template.

## Data boundaries

Do not carry client identities, branding, prices, dates, or terms from a reference into a new project. Keep rounded billable quantities distinct from physical dimensions and document the rounding basis. Never infer construction measurements from AI illustrations.
